# Portfolio Personal

Portfolio personal de Marcos López construido con React, Vite, Tailwind CSS y Framer Motion.

## Stack

- React 19
- Vite 8
- Tailwind CSS
- Framer Motion
- Lucide React

## Estructura

- Hero
- Proyectos
- Sobre mí
- Contacto

## Scripts

- `npm run dev`: inicia el entorno de desarrollo
- `npm run build`: genera la versión de producción
- `npm run preview`: sirve la build en local
- `npm run lint`: ejecuta ESLint

## Dónde editar el contenido

- `src/data/site.js`: datos principales del perfil, navegación, sobre mí y contacto
- `src/data/projects.js`: listado de proyectos y metadatos de cada tarjeta
- `src/assets/AvatarMarcos.jpg`: imagen principal del hero
- `src/assets/backgroundppal.jpg`: fondo atmosférico principal
